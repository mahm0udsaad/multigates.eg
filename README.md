# multigates.eg

Multi Gates for Industrial Development — corporate website.

Built with Next.js 16 (App Router, Turbopack, TypeScript), next-intl (AR/EN), Tailwind CSS, and Supabase (PostgreSQL + Storage).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Environment

Copy `.env.local` with the required Supabase keys:

```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```

## Build

```bash
npm run build
npm start
```
